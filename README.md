🏠 Real Estate Management System
This mini project is a command-line based Real Estate Management System developed using C++ and MySQL. It simulates the operations of a real estate platform by managing property listings, stakeholder details (buyers, sellers, agents, builders), legal approvals, and property registration. The project demonstrates database-driven application development and offers a modular, scalable backend for real estate data handling.

🔧 Features
Add, update, and manage property listings.

Register and manage buyers, sellers, agents, and builders.

Manage legal property approvals and registration processes.

Structured ER-based MySQL database with normalized tables.

Modular C++ source code for data operations via CLI.

🗃️ Tech Stack
Language: C++

Database: MySQL

Environment: Windows/Linux (CLI)

IDE/Compiler: Code::Blocks, VS Code, g++, MySQL Workbench
